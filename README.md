# Ôn tập Tiếng Anh 3 (Global Success)

Web ôn tập Tiếng Anh lớp 3: từ vựng có tranh trong sách, mẫu câu, 11 trò chơi, bài kiểm tra theo bài (tự chấm) và đề giữa/cuối kì.

## Đăng lên GitHub Pages
1. Tạo repository mới, tải 3 file này lên (nhớ cả `.nojekyll`).
2. Settings → Pages → Branch: `main` / thư mục `/ (root)` → Save.
3. Mở đường dẫn `https://<tên-tài-khoản>.github.io/<tên-repo>/`.

Giọng đọc dùng giọng nữ en-US có sẵn trong trình duyệt (Chrome/Edge). Bấm nút ♪ trên menu để đổi giọng, chỉnh tốc độ.
